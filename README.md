# Retail Sales Exploratory Data Analysis
## 📌 Project Overview

This project focuses on Exploratory Data Analysis (EDA) of retail sales data to identify sales trends, customer behavior, product performance, and profitability patterns.
The analysis was performed using Python and popular data analysis and visualization libraries.

## 🎯 Objectives

- Analyze overall retail sales performance
- Identify monthly and quarterly sales trends
- Analyze sales across customer segments
- Analyze category and sub-category performance
- Identify the top-selling products
- Analyze profit across sub-categories
- Explore relationships between numerical variables
- Generate business insights and recommendations

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 📊 Analysis Performed

### Sales Analysis
- Monthly sales trends
- Quarterly sales trends
- Category-wise sales
- Customer segment-wise sales

### Product Analysis
- Top 10 best-selling products
- Category and sub-category analysis
- Profit by sub-category

### Exploratory Analysis
- Data inspection and cleaning
- Statistical analysis
- Correlation analysis
- Data visualization

## 💡 Key Insights

The analysis helps identify:

- Sales trends over time
- High-performing product categories
- Customer segments contributing to sales
- Best-selling products
- Sub-categories with stronger profitability
- Relationships between important numerical variables
